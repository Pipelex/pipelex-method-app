# pipelex-method-apps — moved

This repository is archived. The method-app templates and their initializer, `@pipelex/create-method-app`, now live in the `method-apps/` directory of [Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/tree/main/method-apps), beside the SDKs they are built on.

The initializer keeps its name and is published to npm from there, so `npm create @pipelex/method-app@latest my-app -- --method <bundle>` works as before. The last version released from this repository was 0.5.7, and every later version comes from `Pipelex/pipelex-sdk`.

- **npm:** [`@pipelex/create-method-app`](https://www.npmjs.com/package/@pipelex/create-method-app)
- **Source:** [`method-apps/` in Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/tree/main/method-apps)
- **Issues and pull requests:** [Pipelex/pipelex-sdk](https://github.com/Pipelex/pipelex-sdk/issues)
